# Returns and exchanges

## Standard return window

Velora accepts returns within **30 days of delivery** for a full refund to the original payment method. Items must be unworn outdoors, in original condition, with tags and the original shoe box. Returns are free for Velora Club members. Non-members pay a **$6.95** return shipping fee, which is deducted from the refund. The fee is waived when the return is due to a Velora error or a defect.

## 30-day comfort guarantee (footwear)

Velora footwear is covered by a **30-day comfort guarantee**. If shoes feel uncomfortable, customers may exchange them for a different size, width or model within 30 days of delivery, **even if they have been worn indoors or lightly worn outdoors** (no visible sole wear, no damage). Comfort-guarantee exchanges are always free, including return shipping. Each order line can use the comfort guarantee **once**. If the customer prefers a refund instead of an exchange under the comfort guarantee, store credit for the full amount is offered. A cash refund for worn items is not available.

## Exchanges

Exchanges can be for a different size, width, color or model. If the new item costs more, the customer pays the difference. If it costs less, the difference is refunded to the original payment method. Velora ships the replacement **as soon as the exchange is created** (advance exchange). The customer then has **14 days** to send the original item back using the prepaid return label. If the original is not received within 14 days, the price of the replacement may be charged.

## Return labels

Prepaid return labels are emailed as a PDF and a QR code (for drop-off without a printer). A return label stays valid for **14 days**. Drop-off points: any partner carrier location. Agents can generate a new label if the old one expired.

## Non-returnable items

Final-sale items (marked "Final sale"), gift cards, underwear and socks (hygiene), and personalized or engraved items cannot be returned unless defective.

## Return refund timing

Refunds for returns are issued within **2 business days after the warehouse receives the item**. Banks typically take 3–10 business days to show the refund. See also the refunds policy.
