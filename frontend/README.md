# Supfeel frontend

Next.js 16 (App Router) + Tailwind v4. Pages: `/` (landing) and `/chat` (agent chat).

```bash
npm install
cp .env.example .env.local   # NEXT_PUBLIC_API_URL=http://localhost:8000
npm run dev                  # http://localhost:3000
```

Design source of truth: `../docs/project/design-system.md` and `../docs/design/landing-reference.png`.
Feature context: `../docs/features/landing-page/` and `../docs/features/chat-experience/`.
